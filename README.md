# МАЯК

**Маяк** — приложение для планирования попутных поездок между сёлами и городами.
Идея: не вызывать такси, а обозначать свои планы и находить людей, которым по пути.

## Текущая версия (0.1.0, локальная бета)

- Тёмный графитовый интерфейс с синими акцентами.
- Оригинальная иконка маяка, корректное название **Маяк** на Android.
- Создание маяка: «Еду сам» / «Ищу место», пункты, дата, время, количество мест, цена и комментарий.
- Список собственных планов, удаление и хранение на устройстве даже без интернета.
- **Важно:** общего сервера, регистрации, настоящих пассажиров, живой ленты и совпадений пока нет. Это не готовая служба перевозок.

## Где скачать APK

Открой [Releases](https://github.com/arladiy96-commits/Mayak/releases/latest) и скачай файл `Mayak-v*.apk`.
APK автоматически собирается GitHub Actions при каждом пуше в ветку `main`
и при ручном запуске workflow **Android APK**.

## Для разработчиков

Стек: Flutter / Dart, локальное хранение `shared_preferences`.

В GitHub Actions генерируется стандартная Android-обвязка:

```bash
flutter create --platforms=android --project-name=mayak --org=kz.mayak .
python -m pip install pillow
python tools/generate_icon.py
python tools/configure_android.py
flutter pub get
flutter test
flutter build apk --release
```

Указанные команды также можно выполнить локально с установленным Flutter SDK.
Графика иконки генерируется из кода, никакие внешние картинки для сборки не требуются.
